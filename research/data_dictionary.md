# Rahgir dataset schema (proposed)

| Field | Type | Meaning | Provenance / caution |
|---|---|---|---|
| `route_id` | string | Unique origin-destination experiment id | Generated by experiment runner |
| `case_name` | string | Human-readable route pair | User-selected; not a performance label |
| `retrieved_at` | ISO-8601 | Provider retrieval timestamp | Required for every live snapshot |
| `provider_id` | string | Geocoder/router/POI source identifier | Store provider version if exposed |
| `origin_lat`, `origin_lon` | float | Resolved origin coordinate | Nominatim / licensed geocoder |
| `destination_lat`, `destination_lon` | float | Resolved destination coordinate | Nominatim / licensed geocoder |
| `route_geometry` | GeoJSON LineString | Road route geometry | Routing provider; not a straight line |
| `base_distance_m` | float | Provider road distance | Unit: metres |
| `base_duration_s` | float | Provider road duration | Traffic assumptions vary by provider |
| `poi_source_id` | string | Stable source identifier, e.g. OSM type/id | Preserve attribution and licence |
| `poi_lat`, `poi_lon` | float | POI coordinate | Source coordinate; flag missing/invalid |
| `poi_tags` | JSON object | Raw source tags | Do not infer absent values |
| `poi_category` | string | Normalized category | Version the mapping function |
| `corridor_distance_m` | float | Perpendicular distance to route geometry | Computed geospatial field |
| `route_progress` | float | Closest projected along-route fraction | Computed in [0,1] |
| `leg_time_matrix_s` | matrix | Road-network travel times | Store provider response and null reachability |
| `leg_distance_matrix_m` | matrix | Road-network distances | Same ordering as coordinates |
| `opening_hours_raw` | string/null | Source opening-hours expression | Keep raw value; parser may return unknown |
| `hours_parser_status` | enum | open / closed / unknown | Unknown on unsupported syntax |
| `preference_vector` | JSON | Explicit user-supplied preferences | Consent and data minimisation |
| `safety_evidence` | JSON | Source-backed segment evidence | Only authoritative/licensed sources; unknown allowed |
| `community_report_ids` | array | Related crowd reports | User-generated, never automatically ground truth |
| `itinerary_stop_ids` | array | Selected POIs in order | Output of versioned optimizer |
| `optimizer_version` | string | Algorithm/version/parameters | Reproducibility |
| `objective_vector` | array | Raw objective values | Store directions and units |
| `constraint_status` | JSON | Feasible flags and violation values | Hard constraints |
| `relevance_judgement` | enum/int | Human relevance annotation | Annotator id pseudonym; consent and rubric |
| `data_partition` | enum | synthetic / live / human-labelled | Never merge silently |

## Dataset separation

Synthetic fixtures must carry `data_partition=synthetic` and a conspicuous warning. They cannot be used for route distances, POI truth, opening hours, accident rates, cultural validity, or user satisfaction in a paper. Live provider data must preserve provider attribution and be checked for redistribution restrictions before publication. OSM-derived database redistribution has ODbL obligations; review the applicable legal terms before publishing combined or derived datasets.
