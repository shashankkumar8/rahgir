# Data directory

This directory is intentionally empty in the checked-in build. No live route or POI snapshots were retrieved in the creation environment. Do not add personal data, private route histories, or OSM-derived datasets without reviewing retention, attribution and licensing obligations.

The runnable optimisation benchmark is in `research/results/paper_benchmark/` and is synthetic. Its limitations are described in `research/DATASET_CARD.md`. Future live snapshots should be partitioned from synthetic fixtures and should include provider, retrieval timestamp, licence, attribution, request parameters and raw-response provenance.
